Two AIs, one job each

Dani Agent uses exactly two AI programs you already sign in to: Claude Code and Codex. One writes, the other checks, and plain tests settle what works.

Claude

Plans and reviews

Splits your product into small steps, rates how hard each one is, and reviews every change with no tools at all: it can read and reply, nothing else.

Codex

Writes the code

Builds one step at a time inside a Windows sandbox with no network access. Changes outside that step's files are thrown away.

Tests

Prove each step

Every step's tests run on your PC before it is kept. A step that fails is corrected, or tried again with a stronger model.

How it works

You make one decision. Dani Agent shows you exactly what an approval covers, then carries the build through on its own.

  1. Describe itType what the product should do, or attach a Word, PDF, text, CSV or JSON specification.
  2. Approve onceSee which sessions the build may use, then approve. Nothing runs before that.
  3. Claude plansThe product becomes a short list of steps, each with its files, tests and difficulty.
  4. Build, test, reviewCodex writes each step, its tests run, and Claude reviews it before it is kept.
  5. Get the productPreview it in the dashboard, open its folder, or download it as a zip.

Keeps going on its own

An approved build does not stop because something went wrong once. It stops when you cancel it, or when an attached file can no longer be read safely.

Retries with growing pauses

A step that does not pass is tried again, with a stronger model for hard work and pauses of up to an hour between tries.

Waits out usage limits

When your Claude or Codex limit is used up, the product pauses and goes on by itself at the time it shows you.

Survives restarts and updates

Finished steps are kept. After a restart, or when Claude Code or Codex update themselves, the build picks up where it was.

Polishes on request

Small review notes can be handed back to Codex in one polish pass; it fixes the ones it agrees with and says why for the rest.

Your PC, your accounts, your data

Dani Agent is local software. There is no Dani Agent account and no server in the middle.

  • Your own subscriptionsIt runs the official Claude Code and Codex programs with your sign-ins. No API keys, no proxy, no hidden billing.
  • A dashboard only you can openIt listens on 127.0.0.1 and opens with a private link for each start.
  • Products stay on your diskCode, history and settings live in a private work folder that only your Windows account can open.
  • Sandboxed codeGenerated code and its tests run in a Windows sandbox, and every process is held in a Windows Job that is closed when the work ends.
  • A reviewer that cannot actClaude reviews with no tools, plugins or hooks, and Dani Agent checks that before every session.
  • Checks itself firstWhen Dani Agent changes, its own source is reviewed by Claude before it builds anything again.

Good to know. Local does not mean offline: while it builds, your descriptions, code and test results are sent to Anthropic and OpenAI through their programs, under your accounts' terms. Review every product before you use it; tests and AI review do not replace your own checks.

What it builds

Small, single-user software that runs on your own computer, with nothing to install.

Websites and web apps

Plain HTML, CSS and JavaScript with a tiny Node.js server. Data in the browser or in local files.

Python apps and scripts

Command-line tools and small programs using only Python's standard library.

Not yet

Accounts and logins, hosted services, payments, or downloaded packages. Those are outside what Dani Agent has been tested on.

Get started

Setup takes a few minutes. Start without any AI to look around first.

  1. Download and unzipExtract the whole zip to a folder you control. Do not run it as administrator.
  2. Look around for freeDouble-click Start-Dani-Offline.cmd. AI sessions stay switched off in this mode.
  3. Connect your accountsStart Start-Dani-Dashboard.cmd. The Connect page finds your programs and guides you through sign-in and a private work folder.
  4. Describe your first productAfter its safety checks pass, choose New product and start small.

Questions

Is Dani Agent free?

Yes. Dani Agent is free and open source under the Apache License 2.0. You need your own Claude and Codex (ChatGPT) plans, and their prices, usage limits and terms apply.

Which AIs does it use?

Exactly two: Claude through Claude Code, which plans and reviews, and Codex, which writes the code. It does not use API keys and has no fallback to other providers.

Does my code leave my computer?

Your products and history are stored on your PC. To build them, your description, the code and test results are sent to Anthropic and OpenAI through their official programs, as with any use of those tools. Dani Agent itself sends nothing anywhere else.

How many sessions does a build use?

The approval screen shows it: usually one Codex and one Claude session per step, plus one planning session, and more if a step needs corrections or retries. A step that keeps failing is tried again until it passes, so a hard product can use a lot of your allowance. You can cancel at any time.

What happens when my usage limit runs out?

The product pauses and shows when it will try again. Finished steps are kept, and the build goes on by itself once your limit resets.

Does it work on a Mac or on Linux?

Not yet. Dani Agent relies on Windows' sandbox and Windows Job containment to keep generated code in check, so it is Windows 11 only for now.

Does my computer need to stay on?

Yes. Dani Agent runs on your PC, so builds pause while it is off or asleep and carry on when it is back.

Is it ready for important work?

It is an early preview. It is tested on the developer's machine, including real builds checked by hand, but other Windows setups are not qualified yet. Start with small products and review what it builds.

Where do I report a problem?

Open an issue on GitHub with your Windows version, the Dani Agent release and the steps to reproduce. Remove private details from logs and screenshots first.
